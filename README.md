# beecastle-website

The BeeCastle marketing site (www.beecastle.com). Astro 7 + Tailwind 4, static,
deployed to Netlify.

```bash
pnpm install
pnpm dev      # http://localhost:4321 (runs as a background daemon: pnpm astro dev logs / stop)
pnpm build    # into dist/
pnpm preview
```

Read [CLAUDE.md](CLAUDE.md) before changing anything: it covers where content
lives, the design tokens and the house rules.
